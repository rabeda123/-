# EasyFit in Fun
אפליקציה לירידה במשקל עם תפריט קליל בקלות ובכיף

אפליקציית ווב (PWA) שאפשר להתקין על מסך הבית בטלפון. כל הנתונים נשמרים מקומית במכשיר.

## מה יש בגרסה הראשונה
- **היום** – כל ארוחות התפריט לפי שעות, כפתור "אכלתי ✔" עם בחירת החלופה שאכלת, ומונה כוסות מים (יעד 12).
- **תזכורות** – התראה בשעת כל ארוחה, תזכורת נוספת אחרי שעה אם לא סימנת, ותזכורות מים לאורך היום (רק כשאתה מפגר אחרי הקצב).
  - לתזכורות שעובדות גם כשהאפליקציה סגורה: הגדרות ← "הוסף תזכורות ליומן בטלפון" (קובץ ‎.ics עם התראות יומיות).
- **מלאי** – מזינים כמה יש מכל מוצר. כשמסמנים ארוחה, הכמות יורדת מהמלאי אוטומטית. האפליקציה מחשבת לכמה ימים המלאי יספיק.
- **קניות** – רשימה אוטומטית של מה שלא יספיק לשבוע הקרוב, השוואת מחירים בין שני סופרים (ברירת מחדל: שופרסל ורמי לוי), הסל הזול ביותר ופיצול אופטימלי. תזכורת קניות יומית כשמוצר עומד להיגמר מחר.
- **מעקב** – רישום משקל עם גרף, והיסטוריית עמידה ביעדים ב-14 הימים האחרונים.
- **הגדרות** – שעות ארוחות, יעד מים, ברירות מחדל לחלופות, שמות סופרים, גיבוי ושחזור.

> ⚠️ המחירים הם הערכה ראשונית ולא מחירים חיים – אפשר לעדכן אותם במסך הקניות.
> התפריט הוא דוגמה כללית; מומלץ להתאים אותו עם דיאטנית קלינית.

## הרצה מקומית
```
python3 -m http.server 8000
```
ולפתוח http://localhost:8000

## התקנה בטלפון
1. להפעיל GitHub Pages על הריפו (Settings ← Pages ← Branch).
2. לפתוח את הכתובת בטלפון ← "הוסף למסך הבית" (באייפון: Safari ← שיתוף ← הוסף למסך הבית).
3. בתוך האפליקציה: "הפעל" התראות.
